En esta primera entrega deberán construir la base del proyecto que utilizaremos durante todo el taller. Esta actividad reúne todos los contenidos vistos, por lo que deberán aplicar componentes, directivas, data binding y pipes.
 
🎯 Objetivo de la actividad  
Construir una aplicación inicial en Angular que muestre una lista de elementos utilizando componentes padre–hijo, directivas estructurales y de atributo, manejo de eventos y un pipe personalizado.
 
📌 Instrucciones de la tarea  
Deberán completar todas las siguientes actividades:  
Crear un nuevo proyecto Angular usando Angular CLI.  
Explorar la estructura del proyecto e identificar sus carpetas y archivos principales.  
Crear un componente principal llamado contact-list (o item-list).  
Crear un componente hijo llamado contact-card (o item-card).  
Crear un arreglo estático en el componente principal con al menos 5 elementos (nombre, email, estado u otros campos).  
Enviar los datos del componente padre al hijo utilizando property binding.  
Mostrar la lista en pantalla utilizando el componente hijo.  
Usar *ngFor para renderizar dinámicamente la lista.  
Usar *ngIf para mostrar un mensaje cuando la lista esté vacía.  
Aplicar estilos dinámicos con ngClass o ngStyle según alguna condición (por ejemplo, estado del contacto).  
Agregar un botón en cada tarjeta para marcar un contacto como “favorito”, “activo” u otro estado que definan.  
Manejar el clic con event binding.  
Crear un pipe personalizado para formatear algún dato (nombre, estado, email, etc.).  
Aplicar el pipe dentro del componente hijo.  
📤 Entrega requerida  
Deberán enviar:  
1. Capturas de pantalla  
Proyecto ejecutándose.  
Lista renderizada con el componente hijo.  
Uso visible de *ngFor, *ngIf, estilos dinámicos y el botón funcionando.  
Pipe personalizado aplicado en la vista.  
2. Código  
Arreglo estático del componente principal.  
Property binding hacia el componente hijo.  
Código del pipe personalizado.  
Lógica del botón (event binding).
